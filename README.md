# 大型トラック 3ヶ月点検・日常点検 記録簿＆かんたん診断

大型トラック・トレーラーの点検を助ける無料のWebツールです。1級自動車整備士が作成。

- **かんたん診断** … 専門知識なしのYes/No形式で要点を確認
- **3ヶ月記録簿** … 自動車点検基準 別表第3 の項目を、質問形式か一覧表で入力 → A4横1枚に印刷／PDF保存
- **日常点検簿** … 日常点検（運行前点検）を入力 → 印刷／PDF保存

公開URL: https://truck-tenken.github.io/truck-inspection/

- `index.html` … ツール本体（1ファイルで完結。サーバー不要）
- ホスティング: GitHub Pages（無料）
- アクセス数の集計に Cloudflare Web Analytics（Cookieなし・個人追跡なし）を利用
- このリポジトリは副業ツール専用で、仕事用のデータは一切含みません
